## Task: fix four bugs in the connected-bank sync card (`components/connected-banks.tsx`, Settings → Connected banks)

A QA audit found these; all four are confirmed in the current code:

1. **Sync now stays enabled while a sync is running.** While the button reads "Syncing…", pressing it again sends a second POST; the server's running guard answers 409 and the card shows an error on an otherwise successful sync. The button's `disabled` (around line 175) checks `busy`, `connection.status !== "active"` and `data.configured`, but not `running(connection)`. Disable it while running.

3. **"Review rows" links to the wrong import after a multi-account sync.** The summary (around line 76–81) sums review rows over all imports but links to `imports[imports.length - 1]`. With imports [review 3, review 0] it links to the one with nothing to review. Link to the import that has review rows; when more than one import has review rows, link to the import list (`/import`) or whatever existing page lists them — check `app/import/page.tsx` for the right target.
4. **The sync summary omits rejected rows.** `SyncImport` already has `rejected_rows`, but the completed text shows only new / already imported / need review, so 4+2+1 is shown for 8 rows. Add the rejected count (e.g. "· 1 rejected") when it is non-zero, matching the existing style.
