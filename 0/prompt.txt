## Build
1. **After the call, in the chat:** when a call ends, save one call record in the conversation and show it as a **call summary card**:
   - duration;
   - a short summary (2–4 bullet points) generated by the workspace's chat model from the call transcript, after the call ends and not blocking hang-up; use Next `after()` like the chat route does;
   - the cards created during the call, with their current state;
   - anything still running when the call ended;
   - a **collapsible full transcript** (both speakers, in order, from the live caption turns the client collected).

   Keep the existing per-request messages, but render the ones that came from that call grouped or collapsed inside the call card, so the chat doesn't show the same exchange twice. Pick the simplest storage, for example a `messages` row with role `assistant` and a `moneo-call` block, or a small `voice_calls` table. Validate with Zod. Bound the transcript size (e.g. 50 KB) and the summary prompt input.
2. **Voice picker in Settings:** add a voice choice to workspace settings (see `lib/settings.ts` and the Settings page for how AI settings like `ai_models` are stored and edited). Include GPT-Live voices: check the installed `@ai-sdk/openai` types and OpenAI docs for valid `gpt-live-1` voices; "marin" is the current default, and "cedar" is another known option. Add a **Play sample** button. It calls a small authenticated route that returns a short TTS clip (OpenAI `/v1/audio/speech`, `gpt-4o-mini-tts`, the same voice name, a friendly line like "Hey, it's Moneo. Want me to check your spending?"). Cache the clip per voice in memory or with HTTP caching. `/api/voice/call` must use the chosen voice.
3. **Separate model for calls:** add a "Voice call" entry to the AI models setting (the same place as the chat model; see `AI_AGENTS` in `lib/settings.ts` and `modelForSettings` in `lib/ai/provider.ts`). It defaults to the chat model. Call-mode `/api/chat` requests use it, so the user can pick a faster model for calls.
4. **Typed message during a call:** the previous PR says a typed message in the call starts a task, but it's unverified whether GPT-Live speaks its answer, because there's no delegation for it. Make it work: for example, deliver the result with `session.commentary.append` and `delegation_id: null`, or with `session.instructions.append` telling it to say the result. Check the GPT-Live docs (https://developers.openai.com/api/docs/guides/live-delegation) and test it live.
