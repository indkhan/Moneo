   `claudeEnv()` removes the variables, but adapter 4.4.1 builds its final environment as `{ ...getBaseProcessEnv(), ...settings.env }`. Its inherited environment includes `ANTHROPIC_*` and `CLAUDE_*`, so omitted keys return.

2. **[P1] Selecting Claude silently moves GPT overrides from ChatGPT to the OpenAI API key.**

3. **[P2] Cancel does not stop Claude’s internal tool loop.**  
   [app/api/chat/route.ts:297](/C:/Users/mgsuk/.t3/worktrees/Moneo/t3-64f54dae-3df1ae8e1df1576b/app/api/chat/route.ts:297)

   Cancellation updates the database. `stopIfCanceled()` normally notices it in `prepareStep`, but Claude’s entire internal loop occupies one AI SDK step. After that step starts, ordinary finance tools never refresh the cancellation state.

   The UI reports cancellation while Claude can continue reading data and consuming plan usage until completion or the timeout. The adapter’s abort support works only once Moneo actually aborts its signal.

   **Fix:** connect saved cancellation to the active controller throughout the run, with cleanup afterward. Check cancellation before each bridged tool too.

   **Fix:** detect libc and prefer the matching package, as the SDK’s own resolver does. Align the desktop build assertion with that selection.
