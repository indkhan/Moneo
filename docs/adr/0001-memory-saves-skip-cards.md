# Confident memory saves skip the card

Every AI write in Moneo is a card the owner accepts, apart from two named exceptions. Memories are a third. When the assistant is confident about something the owner said about themselves, it saves the memory straight away and shows a quiet "Memory updated" line under the reply, with edit and undo. It asks with a "Save this?" chip only when the memory looks important but the assistant is unsure. A memory never changes financial records, it comes only from the owner's own words, and it can always be edited, ended, undone or forgotten. A card for every remembered sentence would make memory too tiring to use, which is why ChatGPT and Claude save without asking too.

The chat and voice models save memories themselves with a tool, in the same turn, rather than a background reader checking every turn: they understand what the owner meant, and no extra model call is spent on each turn. The database stores a memory only when it quotes at least three words of the owner's message or steer in that same turn. If the turn read anything the owner didn't write (an attached file or any tool result), every save from it waits for the owner's Save. The quote proves the memory was prompted by something the owner just said; it can't prove the model summarised it correctly, which is why every confident save shows the owner its wording with Undo. A turn that fails takes back its memory changes. Memories steer answers only; none of them authorises an action or a write.
