# Confident memory saves skip the card

Every AI write in Moneo is a card the owner accepts, apart from two named exceptions. Memories are a third. When the assistant is confident about something the owner said about themselves, it saves the memory straight away and shows a quiet "Memory updated" line under the reply, with edit and undo. It asks with a "Save this?" chip only when the memory looks important but the assistant is unsure. A memory never changes financial records, it comes only from the owner's own words, and it can always be edited, ended, undone or forgotten. A card for every remembered sentence would make memory too tiring to use, which is why ChatGPT and Claude save without asking too.

The chat and voice models save memories themselves with a tool, in the same turn, rather than a background reader checking every turn: they understand what the owner meant, and no extra model call is spent on each turn. The database stores a memory only when it quotes at least three words of the owner's message or steer in that same turn. If the turn has an attached file or was opened from a record, every save waits for the owner's Save; once it reads a tool result, every later save in that turn waits too, and memories can't be ended in it. This is a per-turn rule: text from earlier turns that the assistant repeated, and names in the owner brief, are not tracked, and the quote can't prove the model summarised the owner correctly, which is why every confident save shows its wording with Undo. A turn that fails takes back its memory changes. Memories steer answers only; none of them authorises an action or a write.
