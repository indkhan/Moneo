The feature

One chat. One page. Any number of Home cards.

An artifact is a small app built from your data. You describe it, Moneo builds it, and it refreshes every time you open it.

1 · Ask

Describe it

“Show my Scalable portfolio with an allocation donut.” The artifact gets its own chat with every normal chat tool, the mic and cancel.

The chat reads your data with the same read-only tools as Moneo's assistant, then hands a brief to a designer model.
2 · Page

A full interactive page

HTML, CSS and JavaScript written by the model: charts, tables, what-if sliders. It runs in a sandbox that can't reach the network.

  • ECharts, served by Moneo itself
  • Moneo's colours, light and dark
  • Every version kept
3 · Home cards

Widgets that look native

Any part of it becomes a card on Home, in four sizes. You preview a draft, then add it yourself. Moneo's own React draws it, so it's not an iframe.

  • S · M · L · XL, checked at each size
  • Month switches, sliders, toggles
  • Sits next to the built-in widgets

The model writes the design. Every number comes from the app.

The problem

AI-written code, next to your money

Generating a pretty page is easy. Five things make it hard to do responsibly:

Correct

Numbers can't be guessed

Money is integer minor units with a currency. The model must never type an amount.

Current

Open it next month

It should show next month's numbers, not a snapshot from the day it was built.

Safe

Treat the code as hostile

The model reads your merchants and notes. A prompt injection in a transaction could steer it.

Private

Local-first

Moneo runs on 127.0.0.1. A generated page must have no way to send your data anywhere.

Native

Feels like the app

A Home card should look like Moneo built it, not like an embedded web page.

Each of these became one layer of the architecture. Here's how they fit together.

The AI never writes a number

Why two frames? A page can't be trusted to keep its own policy. Only the parent's frame-src stops the child frame from navigating to a URL with your data in it, so the wrapper exists to hold that header.

Layer 4 · Defence in depth

The sandbox stops code. The check stops markup.

QuickJS can't touch the host, but the tree it returns is still untrusted: a stray url() in CSS is a request. So every node is checked before React sees it.

Elements

Allowlisted HTML and SVG

  • div, table, progress, svg, path, gradients, filters…
  • No a, img, script, form, iframe or <use>
  • No event handlers
Attributes & CSS

Nothing that loads

  • Only url(#local-id), rewritten to the card's scope
  • url(), image-set(), @import refused; backslashes refused so escapes can't spell them
  • CSS parsed with PostCSS, every selector prefixed with the card, keyframes renamed
Kit

The only interactive parts

  • Money, Chart, Tabs, Param, Link, Style
  • Props parsed with Zod .strict(); unknown props refused
  • Kit.Link only goes to Moneo's own pages, by enum

Errors aren't silent: they go back to the designer, which fixes the card before it's ever saved.

Performance

A sandbox on every render, and Home still feels instant

Cache

Keyed by the data itself

sha256([renderer, workspace,
  cardVersion, { data, params, size }])

Same inputs, same tree, so a repeat view skips the sandbox. The data is in the key, so a cached card is never older than its data. 500-entry LRU.

Shared reads

One query, many cards

Cards on one Home share a promise map, so five cards that need balances run that read once.

Streaming

Each card on its own

Every card is its own Suspense boundary. A slow Scalable call delays one card, and an error becomes a message in that card instead of a broken Home.

Ownership

The AI proposes. You publish.

Moneo keeps the history of anything that touches your money. Artifacts follow the same rule.

Versions

Append-only

Every page and card change is a new row in artifact_versions or artifact_card_versions. Nothing is edited in place.

Draft → Home

Your button, not the model's

A new card is a draft you preview at each size. published_version only moves when you press Add or Update, and Home never shows a draft's title.

Reverse path

Clean exits

Remove a card, delete an artifact, reset all data: they drop off Home and are covered by the workspace reset and isolation tests.
