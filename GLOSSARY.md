# Moneo

A personal-finance app one owner runs on their own computer. This glossary covers the assistant's memory of the owner.

## Memory

**Memory**:
Something the owner told Moneo about themselves that Moneo keeps and uses in later chats, voice calls and briefings. Every memory has exactly one kind: Pledge, Plan, Fact, Explanation or Preference.
_Avoid_: note, saved info, context

**Pledge**:
A promise the owner makes about their own money behaviour, such as cutting a payee or capping a category.
_Avoid_: goal, promise, resolution, commitment

**Tracked pledge**:
A Pledge that has a measurable rule (what it covers, the period and the target), so Moneo can judge it kept or broken from the ledger.
_Avoid_: active pledge

**Intention**:
A Pledge too vague to measure. Moneo keeps it but never scores it.

**Plan**:
Something the owner expects to happen to them or their money in the future.
_Avoid_: event, forecast item

**Fact**:
Background about the owner's life that explains their money but is not tied to one payment.
_Avoid_: profile, attribute

**Explanation**:
Why a specific payment, payee or transfer is what it is.
_Avoid_: annotation, tag

**Preference**:
How the owner wants Moneo to talk to them or present things.
_Avoid_: setting

**Validity window**:
The period during which a memory is true for the owner: when it starts and, if it has one, when it stops.

**Superseded memory**:
A memory that a newer statement from the owner has replaced. It is kept as history of what the owner used to think.
_Avoid_: deleted memory, old memory

**Ended memory**:
A memory the owner said is no longer true, with nothing replacing it. It is kept as history.

**Forget**:
Permanently deleting a memory with all its versions and its source text, at the owner's request. Unlike ending a memory, it leaves no history.
_Avoid_: delete, remove

**Nudge**:
A one-off message on Home when a sync or import shows that a Tracked pledge was just broken or is close to its limit.
_Avoid_: alert, notification, reminder

**Declined suggestion**:
A memory Moneo asked to keep and the owner said no to. Moneo doesn't suggest it again for six months, but the owner can still keep it or say it again.

**Source**:
The owner's message, typed or spoken in a call, that a memory came from, with the words it quotes.
