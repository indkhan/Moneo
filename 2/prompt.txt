## Other differences from the Supabase image
- Not bundled: supautils, safeupdate, pg_graphql, pg_net, pg_cron, vault/pgsodium, pg_stat_statements, realtime; no Moneo migration needs them. Without safeupdate, a PostgREST DELETE/UPDATE with no filter is not rejected (RLS still limits it).
- `uuid-ossp` is missing from the Windows Postgres build, so the bootstrap creates it only where available. Nothing in Moneo, GoTrue or Storage uses it.
- Postgres keeps the image settings that change results (UTC, `extra_float_digits=0`, `row_security`, ICU en-US collation). It sets `jit=off` and uses the default `wal_level`.

## Open risks
- **MSVC runtime on Windows:** Postgres imports `vcruntime140.dll`, `vcruntime140_1.dll` and `msvcp140.dll`, which Windows doesn't ship. The packaging needs to bundle them app-local or run vc_redist.
- **macOS PostgREST** links Homebrew's libpq by absolute path (`/opt/homebrew/...` on arm64, `/usr/local/...` on x64). The script now relinks it with `install_name_tool` plus an ad-hoc signature, but only on a mac host, so this is untested. All macOS binaries still need hardened-runtime signing and notarization.
- **Not run on macOS or Linux at all.** Their Postgres archives contain symlinks that Windows can't extract, so they have to be fetched on CI. PostgREST, GoTrue and mkcert did cross-build for all three from here.
- **Node version:** Storage declares `node >=26` and I tested only Node 22. Electron's Node version needs checking.
- **Restore is not crash-atomic.** It first takes a `before-restore` backup, so the old state is recoverable.
